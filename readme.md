# Wiki Swapper

## ![Icon](icon-128.png)

A sleek Chrome extension that lets you instantly swap between Wikipedia and Grokipedia, giving you control over your preferred knowledge source.

## Features

- **Choose Your Preferred Wiki**: Set Wikipedia or Grokipedia as your default and auto-redirect on visits.
- **Manual Swap**: Click the swap button to toggle the current page between the two sites.
- **Dark Mode UI**: A clean, modern popup with dark theme for easy use.
- **Seamless Navigation**: Preserves search parameters and anchors when swapping.

## Installation

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable "Developer mode" in the top-right corner.
4. Click "Load unpacked" and select the project folder.
5. The extension will appear in your toolbar—pin it for quick access.

## Usage

1. Click the extension icon to open the popup.
2. Select your preferred wiki using the toggle.
3. Enable "Auto-swap on visit" to automatically redirect when visiting the non-preferred site.
4. Use the "Swap Current Page" button to manually toggle the active tab.

## Permissions

- **webNavigation**: To detect and redirect wiki visits.
- **storage**: To save your preferences.
- **tabs**: To update the current tab URL.

## Supported Sites

- Wikipedia (en.wikipedia.org)
- Grokipedia (grokipedia.com)
